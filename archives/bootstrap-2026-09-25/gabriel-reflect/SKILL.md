# Melhorar a partir de atrito real

Use quando o usuário pedir melhoria do workflow ou quando uma revisão autorizada trouxer falhas recorrentes concretas. Identifique frequência, custo e efeito no resultado. Diferencie um incidente transitório de uma regra durável; não transforme todo erro numa nova skill.

Verifique instruções, scripts, skills e exemplos existentes. Escolha a menor intervenção adequada: eliminar etapa, corrigir comando, melhorar diagnóstico, ajustar regra ou criar um procedimento. Nenhuma mudança também é uma conclusão válida. Preserve regras específicas de projeto e evite duplicar ferramentas gerenciadas por plugins.

Mostre o problema, a evidência, a alteração proposta e como comparar antes/depois. Se a implementação estiver autorizada, faça a alteração no alvo explícito e valide o comportamento afetado. Pesquisa ou uso desta skill não autoriza editar políticas globais, instalar ferramentas, escrever memória, habilitar captura ou publicar.

Registre medições apenas no local autorizado, preservando custos desconhecidos como desconhecidos. Uma melhoria estrutural validada não é prova de produtividade; compare tarefas representativas antes de afirmar economia. Conhecimento durável só deve ser salvo quando houver autorização própria e escopo definido.
